# 🗄️ Banco de Dados SQLite com Python

Estudos práticos de conexão e manipulação de banco de dados **SQLite** com Python: da criação de tabelas até consultas com junção (JOIN).

## O que foi praticado

- Conexão com banco de dados SQLite
- Criação de tabelas (veículo, marca e outras)
- Inserção de dados
- Alteração de tabelas (`ALTER TABLE`)
- Seleção de registros (`SELECT`)
- Ordenação de resultados (`ORDER BY`)
- Consultas com junção entre tabelas relacionadas (`JOIN`)
- Organização do código com um arquivo de modelo

## Arquivos

| Arquivo | Descrição |
|---|---|
| `Desenvolvendo um script Python com conexão a banco de dados.py` | Conexão com o banco |
| `criação de tabels.py` | Criação das tabelas |
| `tabela veiculo.py` / `tabela de marca.py` | Tabelas de veículos e marcas |
| `Inserção de dados em tabela.py` | Inserção de registros |
| `alterando tabela veículo.py` | Alteração de estrutura da tabela |
| `seleção de registros em uma tabela.py` | Consultas simples |
| `botanto a tabela em ordem.py` | Ordenação de resultados |
| `Seleção de registros utilizando junção e de registros relacionados.py` | Consultas com JOIN |
| `modelo.py` | Modelo de dados |
| `meu_banco.db` / `eventos.db` | Bancos SQLite gerados |

## Tecnologias

Python · SQLite (`sqlite3`) · SQL

## Como executar

O módulo `sqlite3` já vem com o Python, então não é preciso instalar nada.

```bash
python "criação de tabels.py"
```
